## 📚 About Linux

Linux is a free and open-source operating system based on the foundations of UNIX.

Linux is widely used in:

- Cloud Computing
- DevOps
- Servers
- System Administration
- Networking
- Cybersecurity
- Software Development

### Key Features of Linux

- Free and Open Source
- Secure
- Multi-user
- Multitasking
- Lightweight
- Command-line based system administration

## 💻 Basic Linux Commands

| Command | Purpose |
|--------|---------|
| `sudo su` | Switch to root user |
| `mkdir` | Create a directory |
| `ls` | List files and directories |
| `ls -a` | Display all files including hidden files |
| `ls -l` | Display files in detailed format |
| `cat` | Display or create file content |
| `stat` | Display file or directory information |
| `touch` | Create an empty file or update timestamp |
| `clear` | Clear terminal screen |
| `tac` | Display file content in reverse order |
| `rev` | Reverse characters of each line |
| `rmdir` | Remove an empty directory |
| `cd` | Change directory |
| `cd ..` | Move to the parent directory |
| `rm` | Remove a file |
| `rm -rf` | Remove a directory and its contents |
| `top` | Monitor running processes |
| `pwd` | Display current working directory |
| `history` | Display previously executed commands |
